🎯 YOUR NEXT STEPS

1. CREATE GITHUB REPOSITORY
   • Go to github.com/new
   • Name: my-bot-army
   • Private: Yes
   • Don't initialize with README

2. UPLOAD THESE DOCS
   • Download all files from this folder
   • git init, git add ., git commit
   • Push to GitHub

3. BUILD THE CODE
   • Open Claude Code
   • Share the repository
   • Say: "Read CLAUDE_CODE_PROMPT.md and build all files"
   • Claude Code will create all Python, JavaScript, and config files

4. DEPLOY TO SERVER
   • Follow DEPLOYMENT.md OR QUICKSTART.md
   • Clone repo to /opt/bot-farm/
   • Add your Anthropic API key to .env
   • Start as systemd service

5. TEST & LAUNCH
   • Test on LAN first
   • Embed widget on client website
   • Monitor and iterate

🏗️ ARCHITECTURE OVERVIEW

Client Websites → JavaScript Widget → Your Server → Claude API
                                      ↓
                          /opt/bot-farm/
                          ├── Bot 1 (Port 5000)
                          ├── Bot 2 (Port 5001)
                          └── Bot N (Port 500N)

Each bot:
  • Custom personality (prompts.py)
  • Own port and systemd service
  • Embeddable via <script> tag
  • Powered by Claude Sonnet 4.5

💡 KEY CONCEPTS

• botfarm user: Non-privileged system user running all bots
• /opt/bot-farm/: Main project directory for all bots
• systemd service: Keeps bots running 24/7
• Widget snippet: Simple <script> tag for any website
• Shared components: Reusable code across all bots
• Claude Code: Builds the actual application code

🚀 QUICK COMMANDS

# View bot status
sudo systemctl status bot-keystone

# View logs
sudo journalctl -u bot-keystone -f

# Restart bot
sudo systemctl restart bot-keystone

# Switch to botfarm
sudo -u botfarm bash

# Update code
cd /opt/bot-farm && git pull origin main

# Test health
curl http://localhost:5000/health
