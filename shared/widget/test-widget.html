Test Status

The chat widget should appear in the bottom-right corner of this page. Click the blue bubble to open the chat window.

Widget Features

Floating Bubble

Blue circular chat button fixed to the bottom-right corner

Chat Window

Expandable interface with message history and input field

Typing Indicator

Animated dots showing when the bot is processing

Session Persistence

Conversation ID stored in localStorage for continuity

Embed Code

To embed this widget on your website, add this script tag:

<script src="https://botfarm.qzz.io/widget.js" data-bot-id="therapist" async></script>

Configuration Options

  • data-bot-id (required) - Bot identifier (e.g., "therapist")
  • data-bot-name (optional) - Display name in header (default: "Assistant")
  • data-position (optional) - "bottom-right" or "bottom-left" (default: "bottom-right")
  • data-theme (optional) - "light" or "dark" (default: "light")
  • data-api-url (optional) - Override API base URL (default: same origin)

Test Instructions

  1. Look for the blue chat bubble in the bottom-right corner
  2. Click the bubble to open the chat window
  3. Type a message and press Enter or click Send
  4. Verify the typing indicator appears while waiting
  5. Check that the bot response appears correctly
  6. Test the close button (×) to minimize the chat
  7. Reopen and verify session persistence

Mobile Testing

  • Resize browser to < 480px width or use device emulation
  • Verify chat window becomes full-width
  • Check bubble size reduces to 50px
  • Confirm tap targets are at least 44px

Security Features

  • HTML escaping prevents XSS attacks
  • No external dependencies (zero supply chain risk)
  • Session IDs stored in localStorage (no sensitive data)
  • Graceful API error handling
