QUICK START GUIDE
================================================================================

1. Setup PostgreSQL with pgvector (Docker recommended)
-------------------------------------------------------
```bash
docker run -d --name mybotarmy-db -p 5432:5432 \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=mybotarmy \
  pgvector/pgvector:pg16
```

2. Configure Environment
-------------------------
```bash
cp .env.example .env
# Edit .env and set:
# - DATABASE_URL
# - SECRET_KEY
# - ANTHROPIC_API_KEY (from https://console.anthropic.com)
```

3. Install Dependencies
-----------------------
```bash
cd my_bot_army
pip install -r requirements.txt
```

4. Start Application
--------------------
```bash
uvicorn app.main:app --reload
```

Application will auto-create:
- pgvector extension
- All database tables
- Vector indexes

5. Test Endpoints
-----------------
```bash
# Health check
curl http://localhost:8000/health

# API documentation
open http://localhost:8000/docs

# Admin dashboard
curl http://localhost:8000/api/v1/admin/dashboard
```

6. Complete Workflow Test
--------------------------
```bash
# 1. Create client
curl -X POST "http://localhost:8000/api/v1/clients/" \
  -H "Content-Type: application/json" \
  -d '{"name": "Acme Corp", "email": "admin@acme.com"}'

# 2. Create bot
curl -X POST "http://localhost:8000/api/v1/bots/" \
  -H "Content-Type: application/json" \
  -d '{
    "client_id": 1,
    "name": "Support Bot",
    "system_prompt": "You are a helpful customer support assistant."
  }'

# 3. Deploy bot
curl -X POST "http://localhost:8000/api/v1/bots/1/deploy"

# 4. Upload knowledge base document
curl -X POST "http://localhost:8000/api/v1/documents/" \
  -H "Content-Type: application/json" \
  -d '{
    "bot_id": 1,
    "title": "Product FAQ",
    "content": "Our product costs $99/month and includes 24/7 support.",
    "source": "faq.txt"
  }'
# Embedding automatically generated ✓

# 5. Create conversation
curl -X POST "http://localhost:8000/api/v1/conversations/" \
  -H "Content-Type: application/json" \
  -d '{"bot_id": 1, "source": "web"}'

# 6. Chat with bot (RAG + Claude API)
curl -X POST "http://localhost:8000/api/v1/conversations/chat" \
  -H "Content-Type: application/json" \
  -d '{
    "conversation_id": 1,
    "message": "How much does your product cost?"
  }'
# Returns real Claude response with RAG context ✓
# Usage automatically logged ✓
```

ARCHITECTURE OVERVIEW
================================================================================

Request Flow for Chat:
  1. POST /api/v1/conversations/chat
  2. Validate conversation and bot status
  3. Save user message to database
  4. RAGService.get_context_for_query()
     → Embed user query
     → Vector search in documents table
     → Return top-K relevant documents
  5. ClaudeService.get_response()
     → Build messages from conversation history
     → Inject RAG context into system prompt
     → Call Anthropic API
     → Extract response and tokens
  6. Save assistant message
  7. Background task: log usage for billing
  8. Return chat response

Database Schema:
  clients (1) ──< bots (M)

  clients (1) ──< usage (M)
